РР-300А совпадает с исполнением РР-300-238 под ЯМЗ-238 (колокол Ø562). Модель повторяет исполнение под 3Д6/3Д12 с колоколом Ø650 и 20-пальцевой муфтой, как на фото владельца; у РР-300-238 муфта 10-пальцевая. Оси, высоты и лапы у обоих исполнений одинаковые, поэтому их расхождения с чертежом считаются ошибками модели. Значения КОМПАС прочитаны по маленьким превью.

Что известно неточно

  • Положение и размер лап: по фото они меньше и ближе к двигателю, чем по Рис. 2. Нужен замер рулеткой.
  • Задняя алюминиевая плита на фото из трёх частей; контур по одному снимку не прочитать.
  • Корпус механизма управления упрощён.
  • Нет цинковой планки над решёткой и скоб на ободе колокола.
  • Файлы КОМПАС (.frw) прочитаны только по превью: на Mac их нечем открыть.
  • В браузере нет рельефа литья и тонких фактур: они есть только в фоторендере.
Модель построена по руководству по эксплуатации, каталогу, фото владельца и габаритному чертежу. Это рабочая версия для проверки, не конструкторский документ. Цвета и фактуры в браузере упрощены по сравнению с фоторендером.
